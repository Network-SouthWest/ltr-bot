Boring Introduction Bit

This Privacy Policy relates to LTR Bot (LTR-bot#6152), which is owned, created, managed, and hosted by amphibious_rock ,under the personal organisation of Network SoutWest. For any requests or enquiries ect, I can be contacted on discord by messaging amphibious_rock or in the Discord server.

1. What is collected

The bot collects your user ID , username, roles and message content.


2. How is it used/Why is it collected

Your user ID and username are used for identification in the logs see section 3 . Your roles in the server are collected to check if you do or do not have permission to do certain actions ect. And finally, message content is collected to be reviewed for content, for several of the features.


3. What is stored

User ID and usernames are not stored, nor is any data corresponding to them, messagages you send and the content within them are not stored either.

4. Legal Basis for Processing (GDPR)

Boring legal bit. The basis of processing is under Legitimate Interest (needed for it to function)

5. Data, Storage, and Security

All data is processed on the server in South West England, the data is encrypted in transit, from the discord servers to the bot server and back. Only I have access to the data, and it is protected against unauthorised access, with the standard network firewalls and protection, and a password on the server for login.


6. Data Retention

All the data listed in section 2 is only temporarily stored in the logs, which are only temporary and are deleted after a short period of time and are used for debugging. Server configuration data such as channel and role IDs are stored in a locally stored config file that is not publically accessible. Server config data is retained for the lifetime of the bot's operation or until a deletion request is received.


7. Data sharing and Third parties

No data is shared or sent to any third parties whatsoever.


8. User Rights

You could request a copy of any data stored of you, but there isnt any. You can also request all your data be deleted, but the same follows.


9. COPPA

The minimum age of use for discord is 13 according to their own ToS, and we do not knowingly collect data of anyone under 13 years old.


10. Changes to the Privacy Policy

Any changes to the privacy policy will be announced in the discord server.
